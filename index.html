Using AI to Turn Earnings PDFs into Interactive Web Reports

This is the live workflow for converting quarterly earnings reports into slick, interactive HTML reports using AI.

Step 1: Upload PDF to AI

  • Ask AI to read the PDF and create an HTML version with tabbed sections for each page or topic.
  • Each tab should correspond to a logical section like "Summary", "Income Statement", "Outlook", etc.

Step 2: Iterate on Design

  • Use AI to clean up formatting, styling, and layout until you're satisfied.
  • Add charts or icons if desired using Chart.js or Plotly.js.

Step 3: Extract Structured Data

  • Ask AI to create a JSON version of the key data (e.g., revenue, EPS, margins).
  • This data will later feed into templates for future automation.

Step 4: Create HTML + JSON Template Pair

  • Use AI to write an HTML template with variables like {{revenue}} or {{eps}}.
  • Pair it with the JSON data format the AI generated.

Step 5: Build a Reusable AI Project

  • Store the HTML and JSON templates as source files in your AI assistant or coding environment.
  • Feed it new PDFs to generate new HTML reports automatically.
  • Each report becomes a new version of the website with consistent structure and branding.

Goal

Students will leave knowing how to:

  • Use AI to automate repetitive formatting tasks.
  • Extract and reuse data across templates.
  • Think modularly about content creation with JSON + HTML pipelines.
