Presented by Professor Tauhid Zaman

In this demo, we'll take a raw quarterly earnings PDF and use AI to turn it into a sleek, interactive HTML report with tabs, charts, and reusable templates.

For this demo, the best AI to use is Claude 3.7 Sonnet , available on the Anthropic website. You can also use ChatGPT, but it may not be as effective for this task.

Workflow Download Files Completed Reports

Step 1: Upload PDF to AI

  • Ask AI to read the PDF and create an HTML version with tabbed sections.
  • Each tab maps to a logical section like "Summary", "Income Statement", etc.

Step 2: Iterate on Design

  • Use AI to refine formatting, layout, and style.
  • Add visuals with Chart.js or Plotly.js.

Step 3: Extract Structured Data

  • Ask AI to generate a JSON file with key metrics like revenue, EPS, margins.

Step 4: Create Templates

  • Make an HTML template with variables like {{revenue}}, {{eps}}.
  • Pair it with the AI-generated JSON format.

Step 5: Build AI Project

  • Store the templates and connect the AI to ingest new PDFs.
  • Generate consistent, reusable HTML reports automatically.

Goal

  • Automate tedious formatting with AI
  • Separate data and presentation
  • Build scalable tools for finance & consulting workflows
